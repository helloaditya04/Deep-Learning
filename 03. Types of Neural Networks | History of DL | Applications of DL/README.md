## i.) Types of Neural Networks

### ➜ Feed Forward Neural Networks | Multi-Layer Perceptron

1. **The simplest form** - data flows one direction, **input → hidden layers → output**, no loops.
2. **Used for** basic classification/regression on structured/tabular data.

---

### ➜ Convolutional Neural Network (CNN)

1. Uses **convolutional filters** to detect spatial patterns (**edges, textures, shapes**).
2. **Dominant for image data** - classification, object detection, segmentation.
3. **Key architectures** - LeNet, AlexNet, VGG, ResNet, EfficientNet.
